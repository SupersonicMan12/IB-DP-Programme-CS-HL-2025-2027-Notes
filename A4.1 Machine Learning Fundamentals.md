## A4.1.1 Describe the types of machine learning and their applications in the real world.
- The different approaches to machine learning algorithms and their unique characteristics
- Deep learning (DL), reinforcement learning (RL), supervised learning, transfer learning (TL), unsupervised learning (UL)
- Real-world applications of machine learning may include market basket analysis, medical imaging diagnostics, natural language processing, object detection and classification, robotics navigation, sentiment analysis.

| Type                       | How it learns                                                                                                                                      | Real-world applications                                                                    |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **Supervised**             | From **==labelled==** data (input → known output); predicts labels for new data. Covers classification and regression                              | Medical imaging diagnostics, sentiment analysis, spam filtering                            |
| **Unsupervised (UL)**      | From ==**unlabelled**== data; finds hidden structure or patterns (clustering, association)                                                         | Market basket analysis, customer segmentation                                              |
| **Reinforcement (RL)**     | An agent acts in an environment by trial and error, maximising cumulative ==reward signal==                                                        | Robotics navigation, game AI, self-driving cars                                            |
| **Deep learning (DL)**     | Neural networks with ==**many hidden layers**==; learn features automatically from raw data. Needs lots of data and compute                        | Object detection and classification, natural language processing (NLP), speech recognition |
| **Transfer learning (TL)** | ==Reuses== a model **==pre-trained==** on one task as the starting point for a related task, then fine-tunes it. Needs less data and training time | Adapting an ImageNet model to X-ray diagnosis; fine-tuning a language model                |

## A4.1.2 Describe the hardware requirements for various scenarios where machine learning is deployed.
- The hardware configurations for different machine learning scenarios, considering factors such as processing, storage and scalability
- Hardware configurations for machine learning ranging from standard laptops to advanced infrastructure
- Advanced infrastructure must include application-specific integrated circuits (ASICs), edge devices, field-programmable gate arrays (FPGAs), GPUs, tensor processing units (TPUs), cloud-based platforms, high-performance computing (HPC) centres.

Factors to consider:
- Processing - parallel computation for matrix math
- Storage - size and speed for large datasets
- Scalability - growing with more data or users

| Hardware                     | What it is                                                                                                           | When to use it                                                                              |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **Standard laptop/PC (CPU)** | ==General-purpose== (recall CPU vs GPU), few cores                                                                   | Learning, ==small== datasets, ==simple== models, prototyping                                |
| **GPU**                      | ==Thousands of cores== for parallel maths                                                                            | Training ==deep networks==; the industry standard                                           |
| **TPU**                      | ==Google's ASIC== built specifically for tensor (neural network) operations                                          | ==Very large-scale== training and inference, usually through the ==cloud==                  |
| **ASIC**                     | ==Custom chip for one fixed task==; fastest and most power-efficient, but not reprogrammable and expensive to design | Mass-produced dedicated inference, e.g. ==phone AI chips==                                  |
| **FPGA**                     | = Field-programmable gate arrays. ==Reprogrammable==, flexible hardware with low latency                             | Testing a custom vision-processing circuit on FPGA before committing to an expensive ASIC   |
| **Edge devices**             | Inference runs **on the device** itself (phone, IoT, camera)                                                         | Real-time, offline, privacy-sensitive, low bandwidth, e.g. ==face unlock==, autonomous cars |
| **Cloud platforms**          | Rented GPUs/TPUs on demand (AWS, Azure, GCP)                                                                         | Scalable, ==pay-as-you-go==; privacy, latency. ChatGPT                                      |
| **HPC centres**              | ==Supercomputer clusters==                                                                                           | ==Huge models== (e.g. training LLMs), scientific research                                   |
