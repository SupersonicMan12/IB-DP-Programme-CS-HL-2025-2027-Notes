## A4.3.1 Explain how linear regression is used to predict continuous outcomes.
- The relationship between the independent (predictor) and dependent (response) variables
- The significance of the slope and intercept in the regression equation
- How well the model fits the data—often assessed using measures like r².

Linear regression predicts a continuous value: $\hat y = mx+c$
- $x$ is the independent variable / predictor
- $y$ is the dependent variable / response
- $\hat y$ is the predicted value
- Residual = $y-\hat y$

Know slope and intercept, obtained by fitting the line to minimize the squared errors (residuals) between data points and the line (==least squares==: minimize $\sum(y-\hat y)^2$).
- **Slope $m$**: change in $\hat y$ for every 1-unit increase in $x$; sign gives direction (+ rises, − falls)
- **Intercept $c$**: predicted $\hat y$ when $x=0$; may be meaningless if $x=0$ is outside the data

$r$ is the correlation coefficient ($-1$ to $1$): strength and direction of the linear relationship
$r^2$ ($0$ to $1$) is the share of the variation in $y$ that the model explains, e.g. $r^2=0.85$ means 85% explained; closer to 1 = better fit

Limitations: only captures ==linear== relationships, sensitive to outliers, extrapolation beyond the data is unreliable, correlation $\neq$ causation
## A4.3.2 Explain how classifications techniques in supervised learning are used to predict discrete categorical outcomes.
- K-Nearest Neighbours (K-NN) and decision trees algorithms to categorize new data points, based on patterns learned from existing labelled data
- Real-world applications of K-NN may include collaborative filtering recommendation systems.
- Real-world applications of decision trees may include medical diagnosis based on a patient’s symptoms.

Classification predicts a ==discrete label== (e.g. spam / not spam), learned from ==labeled== training data.

**K-Nearest Neighbors (K-NN)**:
1. Calculate the distance (usually Euclidean) from the new point to every training point
2. Take the $k$ closest points
3. Assign the most common class among them (==majority vote==)
- "Lazy" learner: no training step, all work happens at prediction, so it's slow on large data sets
- Small $k$ is sensitive to noise (overfits); large $k$ blurs class boundaries (underfits); use an odd $k$ for 2 classes to avoid ties
- Features must be ==normalized/standardized== (A4.2.1), otherwise large-valued features dominate the distance
- **Collaborative filtering**: each user is a vector of their ratings → find the $k$ most similar users → recommend items they rated highly

**Decision trees**:
- **Internal nodes** test a feature (e.g. "fever?"), **branches** are outcomes, **leaves** are class labels
- Built by repeatedly choosing the split that best separates the classes (purest groups)
- Predict by following the path from root to leaf
- Easy to interpret ("white box"), but deep trees ==overfit== → limit depth / prune
- **Medical diagnosis**: asks about symptoms one after another and ends at a diagnosis; doctors can follow and verify the reasoning

## A4.3.3 Explain the role of hyperparameter tuning when evaluating supervised learning algorithms.
- Accuracy, precision, recall and F1 score as evaluation metrics
- The role of hyperparameter tuning on model performance
- Overfitting and underfitting when training algorithms

**Confusion matrix**:

|              | Predicted +         | Predicted −         |
| ------------ | ------------------- | ------------------- |
| **Actual +** | True Positive (TP)  | False Negative (FN) |
| **Actual −** | False Positive (FP) | True Negative (TN)  |

| Metric        | Formula                        | Meaning / when it matters                                                                                    |
| ------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **Accuracy**  | $$\frac{TP+TN}{\text{total}}$$ | Share of all predictions that are correct; ==misleading on imbalanced data==                                 |
| **Precision** | $$P = \frac{TP}{TP+FP}$$       | Of predicted positives, how many really are; matters when **FP** is costly (spam filter deleting real email) |
| **Recall**    | $$R = \frac{TP}{TP+FN}$$       | Of actual positives, how many were found; matters when **FN** is costly (cancer screening)                   |
| **F1**        | $$\frac{2PR}{P+R}$$            | Harmonic mean of precision and recall; a single balanced score, useful for imbalanced data                   |
e.g. TP = 40, FP = 10, FN = 20, TN = 30 → Accuracy = 0.70, Precision = 0.80, Recall ≈ 0.67, F1 ≈ 0.73

**Hyperparameters** are set ==before== training, not learned (e.g. $k$ in K-NN, max tree depth, learning rate, number of layers). **Parameters** are learned during training (e.g. weights, slope).

**Tuning**: try different hyperparameter values → evaluate each on a ==validation set== (not the test set), e.g. grid search, random search, cross-validation → keep the best. Goal: balance between over- and underfitting so the model ==generalizes==.

|               | Overfitting                                 | Underfitting                                      |
| ------------- | ------------------------------------------- | ------------------------------------------------- |
| What it is    | Memorizes training data, including noise    | Too simple to capture the pattern                 |
| Symptom       | High training accuracy, low test accuracy   | Low accuracy on both training and test            |
| Typical cause | Too complex (e.g. $k=1$, very deep tree)    | Too simple (e.g. huge $k$, a tree with one split) |
| Fix           | Simplify / prune, more data, fewer features | More complex model, more features, train longer   |

## A4.3.4 Describe how clustering techniques in unsupervised learning are used to group data based on similarities in features.
- Clustering techniques in unsupervised learning group data based on feature similarities
- Real-world applications of clustering may include using purchasing data to segment a customer base.

Clustering is unsupervised. ==K-means==:
1. Choose $k$ the number of clusters
2. Place $k$ centroids at random
3. Assign each point to its nearest centroid
4. Move each centroid to the mean of the points assigned to it
5. Repeat steps 3-4 until convergence

- $k$ is a hyperparameter, chosen with the elbow method: plot total within-cluster distance against $k$ and pick the "bend"
- Weaknesses:
	- The result depends on initial random placement of centroids
	- Sensitive to outliers
	- Assumes clusters are roughly round and similar in size

Explicitly provided real-world application: using purchasing data to segment customer base:
- e.g. High-/low- spending, frequent/occasional customers
## A4.3.5 Describe how learning techniques using the association rule are used to uncover relations between different attributes in large data sets.
- Mining techniques using the association rule and interpretation of the results for a given scenario
- For example, in crime analysis, the techniques may reveal that areas with high rates of vandalism also often experience incidents of theft, assisting law enforcement in predictive policing and resource allocation.

A rule is represented with $X \Rightarrow Y$, meaning if $X$ appears, $Y$ tends to appear too:

| Metric                         | Formula                                            | Meaning                                                                                      |
| ------------------------------ | -------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| $$Support(X)$$                 | $$\frac{\text{count}(X)}{\text{total}}$$           | How often $X$ appears. Clarification: yes, it is                                             |
| $$Confidence(A\Rightarrow B)$$ | $$\frac{\text{count}(X\cap Y)}{\text{count}(X)}$$  | When $X$ appears, how often does $Y$ also appear; conditional probability in MAA             |
| $$Lift(A \Rightarrow B)$$      | $$\frac{Confidence(A \Rightarrow B)}{Support(B)}$$ | $>1$ means $X$ and $Y$ are positively linked; $=1$ means independent; $<1$ negatively linked |
e.g. Crime analysis: 200 areas, 50 have vandalism, 40 have both vandalism and theft, 80 have theft.
